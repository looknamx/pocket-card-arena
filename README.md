# Pocket Card Arena

เกมการ์ดต่อสู้ 2D แนวตั้ง ภาษาไทย ตัวละครต้นฉบับ 8 ใบ พร้อมบอตและห้องออนไลน์จริง

## เปิดเล่น

ต้องมี Node.js 22.12 ขึ้นไป

```powershell
npm install
npm run dev
```

เปิด http://localhost:5173 แล้วเลือก เล่นกับบอต → จัดทีม 3 ใบ → เข้าสนาม

สำหรับรันไฟล์ build:

```powershell
npm run build
npm start
```

เปิด http://localhost:3001 (เซิร์ฟเวอร์เดียวให้บริการหน้าเว็บและ WebSocket)

## เล่นกับเพื่อนผ่านสองหน้าต่าง

1. เปิด URL เดียวกันในสองแท็บ หรือสองหน้าต่าง (ใช้ชื่อแตกต่างกัน)
2. หน้าต่างแรกเลือก เล่นกับเพื่อน → ใส่ชื่อ → สร้างห้อง → คัดลอกรหัส
3. หน้าต่างที่สองเลือก เล่นกับเพื่อน → ใส่ชื่อและรหัส → เข้าห้อง
4. แต่ละคนกด จัดทีม เลือก 3 ใบ ใบแรกเป็นตัวเริ่มต้น แล้วกดยืนยัน
5. ทั้งสองฝ่ายกด พร้อมเข้าสนาม ระบบสุ่มฝ่ายเริ่มก่อน และส่งสถานะเดียวกันให้ทั้งคู่
6. ใช้สกิล แล้วตรวจ HP พลังงาน เทิร์น และบันทึกในทั้งสองหน้าต่าง
7. ลองส่งคำสั่งเร็วซ้ำ ปุ่มล็อกระหว่างเอฟเฟกต์ เซิร์ฟเวอร์ตรวจ revision และรหัสคำสั่งอีกชั้น
8. รีโหลดหน้าต่างหนึ่ง อีกฝั่งแสดงการหลุดและเวลาที่เหลือ เลือก เล่นกับเพื่อน → กลับเข้าห้องเดิม ภายใน 60 วินาที หากไม่กลับจะปรับแพ้
9. เล่นอีกครั้งต้องกดทั้งคู่ แล้วจะกลับห้องเพื่อจัดทีมและกดพร้อมใหม่

## เพื่อนจากอีกเครื่อง

ให้อุปกรณ์อยู่ Wi-Fi/LAN เดียวกัน เปิด npm run dev บนเครื่องเจ้าบ้าน และให้เพื่อนเปิด Network URL ที่ Vite แสดง เช่น http://192.168.1.53:5173 (IP อาจเปลี่ยน ให้ดูค่าที่แสดงตอนเปิดจริง) อนุญาต Node.js ผ่าน Windows Firewall ในเครือข่าย Private หากเชื่อมต่อไม่ได้ตรวจว่าไม่ใช้ guest Wi-Fi ที่แยกอุปกรณ์

หรือใช้ npm run build แล้ว npm start ให้เพื่อนเปิด http://<IP-เจ้าบ้าน>:3001 และอนุญาตพอร์ต 3001

การเล่นผ่านอินเทอร์เน็ตต่างเครือข่ายต้องนำเซิร์ฟเวอร์ Node นี้ไปโฮสต์บนบริการที่รองรับ WebSocket และ HTTPS/WSS หรือใช้ tunnel ที่รองรับ WebSocket ยังไม่ได้ deploy ไปบริการภายนอก หน้าเว็บต้องใช้ origin เดียวกับ /ws และหากมี reverse proxy ต้องส่ง Upgrade header ด้วย โหมดบอตไม่ต้องใช้เซิร์ฟเวอร์ห้องออนไลน์

## กติกาและค่าตั้งต้น

- ทีม 3 ใบไม่ซ้ำ เลือกได้ทีละหนึ่งแอ็กชันต่อเทิร์น
- พลังงานเริ่ม 3 สูงสุด 6 เพิ่ม 1 ตอนเริ่มเทิร์น รวมถึงเทิร์นแรก (ฝ่ายเริ่มเห็น 4)
- โจมตีฟรี ตั้งรับ 1 ท่าพิเศษ 3 คูลดาวน์สองเทิร์นเจ้าของเต็ม ๆ หลังใช้
- สลับโดยสมัครใจได้ 3 ครั้ง ใช้เทิร์น แก้ค่าได้ที่ CONFIG.switches ใน src/cards.js
- หมดสภาพต้องเลือกสำรอง การเปลี่ยนฟรี ไม่เสียเทิร์น/โควตา
- ไฟ > ดิน > ลม > น้ำ > ไฟ ชนะธาตุคูณ 1.25 (+25%) แพ้ธาตุคูณ 0.8 (−20%) ธาตุเดียวกันหรือคู่ตรงข้ามคูณ 1
- สูตร max(1, ATK × multiplier − DEF × .5) → ธาตุ → ตั้งรับ → ปัดจำนวนเต็ม ขั้นต่ำ 1 → โล่ → HP
- ตั้งรับลดความเสียหายโจมตีถัดไป 50% และหมดตอนเริ่มเทิร์นตัวเอง
- เริ่มเทิร์น: เพิ่มพลังงาน ลดคูลดาวน์ทั้งทีม ล้างตั้งรับ ตรวจการเลือกสำรอง
- ก่อนแอ็กชัน: ถ้าสตันข้ามแอ็กชัน ลบสตันแล้วจบเทิร์น
- จบเทิร์นเจ้าของ: ทั้งตัวจริงและสำรองประมวลผล เผาไหม้ → พิษ → ฟื้นฟู → อายุโล่ → อายุบัฟ ATK ตัวตายไม่ฟื้นด้วย regen จากนั้นตรวจผลทีม เปลี่ยนเทิร์น
- เผาไหม้ 5% HP สูงสุด 2 เทิร์น พิษ 4% 3 เทิร์น ฟื้นฟู 5% 2 เทิร์น ATK +20% 2 เทิร์น โล่ 40 หน่วย 2 เทิร์น สตันหนึ่งแอ็กชัน สถานะชื่อเดียวรีเฟรช ไม่เพิ่มชั้น
- เอฟเฟกต์ใส่ตัวเองเริ่มนับในเทิร์นที่ใช้ (รวมเทิร์นนั้นในระยะเวลา) โล่รับความเสียหายทั้งการโจมตีและสถานะ
- ตรวจหมดสภาพหลังโจมตีและหลังชุดสถานะ หากทั้งทีมหมดในแอ็กชัน/ชุดประมวลผลเดียวกันให้เสมอ
- บอตใช้ engine เดียวกัน มีพฤติกรรมโจมตี ใช้ท่าพิเศษ ตั้งรับเมื่อใกล้ตาย และสลับตัวเมื่อเลือดต่ำ
- ทีมและเสียงเก็บใน localStorage สิทธิ์กลับห้องเก็บใน sessionStorage ของแท็บ

## โครงสร้าง

- src/cards.js — ข้อมูลการ์ด สกิล ธาตุ สถานะ และค่าตั้งต้น
- src/engine.js — กติกา pure state transition ใช้ร่วมกันในบอตและเซิร์ฟเวอร์
- src/arena.js — Phaser วาดสนาม idle/เอฟเฟกต์เท่านั้น
- src/main.js + src/style.css — เมนู HUD ภาษาไทยและ responsive
- src/online.js — WebSocket client / reconnect
- server/index.js — สถานะห้อง authoritative ตรวจผู้เล่น เทิร์น พลังงาน คูลดาวน์ โควตา revision และคำสั่งซ้ำ ไม่รับ HP/ดาเมจจาก client
- public/characters/*.svg — ภาพตัวละครต้นฉบับ เปลี่ยนไฟล์ได้แยกจากกติกา
- generate-assets.js — สร้างภาพ SVG สำหรับต้นแบบ

เลือก Phaser สำหรับแอนิเมชัน/สนาม 2D และ DOM สำหรับข้อความไทย/ปุ่มมือถือ ใช้ Vite สำหรับพัฒนาและ build; Node + ws ทำห้องออนไลน์โดยไม่ต้องผูกบริการเสียเงิน

## ตรวจสอบ

```powershell
npm test
npm run build
```

10 automated tests: ทีมไม่ซ้ำ โควตา พลังงาน ตัวตาย ธาตุ โล่ ตั้งรับ คูลดาวน์สำรอง สถานะ/สตัน/ฟื้นฟู/บัฟ การเปลี่ยนฟรี ผลเสมอ และแมตช์บอต 20 รอบ รวม integration test เซิร์ฟเวอร์ WebSocket สองผู้เล่น ตรวจสถานะตรงกัน คำสั่งซ้ำ คำสั่งผิดเทิร์น reconnect และ timeout 60 วินาทีจริง (ชุดทดสอบใช้เวลาประมาณหนึ่งนาที)

ภาพตรวจ UI เก็บที่ output/playwright/ ทดสอบหน้าแรก จัดทีม ต่อสู้บอต ท่าพิเศษ และห้องออนไลน์สองแท็บ หน้าจอ 390 × 844 ไม่มีส่วนควบคุมบังสนาม หน้าจอเตี้ยเลื่อนแนวตั้งได้

## ข้อจำกัดเวอร์ชันต้นแบบ

ห้องเก็บในหน่วยความจำ รีสตาร์ตเซิร์ฟเวอร์แล้วหาย ไม่มีบัญชีหรือ matchmaking และยังไม่ได้โฮสต์สาธารณะ ตัวละครเป็น SVG ต้นฉบับ เอฟเฟกต์เรียบง่ายและเสียงสั้น ไม่มีระบบเลเวล ร้านค้า หรือกาชา ฟอนต์ Google โหลดเมื่อมีอินเทอร์เน็ต หากโหลดไม่ได้ใช้ฟอนต์ระบบ

## สรุปการแข่งขัน

หลังจบแมตช์แสดงชื่อผู้ชนะ/เสมอ จำนวนเทิร์น และรายงานทั้งสองทีม: ดาเมจรวม ตัวทำดาเมจสูงสุด (รองรับอันดับร่วม) พร้อมดาเมจรายตัว ดาเมจที่รับ จำนวนคู่ต่อสู้ที่ล้ม การฟื้นฟูจริง และ HP ที่เหลือ กดรายละเอียดเพื่อแยกดาเมจ HP / โล่

ดาเมจนับเฉพาะความเสียหายจริงที่ลด HP และโล่ ไม่รวม overkill พิษ/เผาไหม้ให้เครดิตตัวที่สร้างสถานะ แม้สลับออกหรือตัวผู้ใช้หมดสภาพแล้ว การรีเฟรชสถานะเปลี่ยนเครดิตเป็นผู้ใช้ล่าสุด การฟื้นฟูนับเฉพาะ HP ที่เพิ่มจริง สถิติเก็บใน engine และส่งจากเซิร์ฟเวอร์ในโหมดออนไลน์ เริ่มแมตช์ใหม่รีเซ็ตทุกค่า แมตช์ที่เริ่มก่อนเพิ่มฟีเจอร์นี้ต้องเริ่มใหม่เพื่อเก็บสถิติครบ

ชุดทดสอบล่าสุด 13 tests เพิ่มการตรวจดาเมจจริง/โล่/overkill เครดิตสถานะขณะสำรอง การฟื้นฟู และสรุปผลเสมอ ภาพสรุปบนมือถือ: output/playwright/summary-mobile.png

## ธาตุ 4 แบบ (อัปเดต)

ไฟ → ดิน → ลม → น้ำ → ไฟ ได้เปรียบเฉพาะธาตุถัดไปในวงจร ธาตุเดียวกันและคู่ตรงข้ามสูสี (เช่น ไฟกับลม ดินกับน้ำ)

| ธาตุ | ตัวละครเดิม |
|---|---|
| ไฟ | ฟ็อกซ์ฟู, ปิ๊งปิ๊ง |
| ดิน | มอสซี่, ปุ๊กปิ๊ก |
| ลม | เห็ดจิ๋ว, โมจิมูน |
| น้ำ | บับเบิลบัน, มิสตี้ |

ชนะธาตุเพิ่มดาเมจโจมตีพื้นฐานและท่าพิเศษ 25% แพ้ลด 20% ใช้หลังหัก DEF ก่อนผลตั้งรับ/โล่ ไม่เปลี่ยนเปอร์เซ็นต์พิษ/เผาไหม้ บัฟเพิ่ม ATK ยังคูณแยกตามกติกาเดิม สรุปการแข่งขันใช้ดาเมจจริงหลังคำนวณธาตุแล้ว

หน้าเลือกทีมและคอลเลกชันแสดงวงจรธาตุ รายละเอียดการ์ดแสดงธาตุที่ชนะ/แพ้ สนามแสดงความได้เปรียบของตัวจริงและบันทึกผลธาตุ ทั้งบอตและออนไลน์ใช้ elementFactor ตัวเดียวกัน แก้ค่าคูณได้ที่ CONFIG.elementAdvantage / CONFIG.elementDisadvantage ใน src/cards.js

## ภาพตัวละครจาก Imagegen

ใช้ built-in image_gen.imagegen สร้างแยกทั้ง 8 ตัว พร้อมพื้นหลังโปร่งใส: ฟ็อกซ์ฟูหางเปลวไฟ, บับเบิลบันหูสายน้ำและโล่ฟอง, มอสซี่สวนดอกไม้/กระถาง, ปุ๊กปิ๊กเกราะหิน, เห็ดจิ๋วภูตหมวกเห็ด, ปิ๊งปิ๊งแผงคอดาว/หางดาวตก, มิสตี้สามหางสายน้ำ และโมจิมูนหูจันทร์เสี้ยว/กระดิ่งสายลม

ไฟล์ที่ใช้จริง: public/characters/{id}-v2.png (512 × 512 RGBA) เก็บต้นฉบับที่ assets/characters/source/{id}-v2.png และ prompt เต็มแต่ละตัวที่ assets/characters/prompts.json ภาพ SVG เดิมยังเก็บไว้เป็นต้นแบบ แก้เฉพาะ path ภาพและคำบรรยายตามเอกลักษณ์ใหม่ ไม่เปลี่ยนค่าสถานะ/ธาตุ/กติกา

ส่งออกไฟล์ขนาดสำหรับเกมอีกครั้งได้ด้วย node scripts/prepare-character-art.mjs (ใช้ sharp ปรับขนาดและบีบอัด โดยเก็บ alpha และไม่แก้งานวาด) แก้ Phaser loader เป็น image เพื่อรองรับ PNG; ตรวจ collection และสนามบนมือถือ พร้อมผ่าน build และ 14 engine tests

## ระบบวางแผนและคอมโบ (เวอร์ชันล่าสุด)

กติกาใหม่ในหัวข้อนี้มีผลแทนคำอธิบายท่าพิเศษ/การตั้งรับในเวอร์ชันก่อนหน้า เปิดปุ่ม “วิธีวางแผน” ในสนามเพื่อดูคำแนะนำ และดูเอฟเฟกต์รายตัวจากคอลเลกชัน

### เจตนาบอต

โหมดบอตใช้ทีมฟ็อกซ์ฟู/บับเบิลบัน/เห็ดจิ๋วและแสดงแอ็กชันถัดไปก่อนผู้เล่นตัดสินใจ แผนถูกเก็บในสถานะเกมและบอตยึดแผนนั้น สตันหรือหมดสภาพทำให้แผนหยุด/เปลี่ยนตัวตามกติกา บอตพิจารณาเลือด ธาตุ พลังงาน การชาร์จ และช่องเวลาคอมโบ ใช้โควตาสลับเพื่อต่อคอมโบที่สถานะยังไม่หมด ในออนไลน์ไม่เปิดเผยแผนของผู้เล่น แสดงเฉพาะการชาร์จที่เกิดขึ้นแล้ว

### คอมโบสองตัว

- น้ำ: การโจมตีของบับเบิลบันและมิสตี้ใส่ “เปียก” 3 เทิร์นของเป้าหมาย
- มอสซี่: การโจมตีใส่ “รากยึด” 3 เทิร์นของเป้าหมาย (เครื่องหมายคอมโบ ไม่ห้ามสลับ)
- ลมโจมตีเป้าหมายเปียก → พายุสายน้ำ ดาเมจ ×1.5 แล้วใช้เปียกหมด
- ไฟโจมตีเป้าหมายรากยึด → รากเพลิงระเบิด ดาเมจ ×1.5 แล้วใช้รากยึดหมด
- ทั้งโจมตีพื้นฐานและท่าพิเศษต่อคอมโบได้ หลังหัก DEF คูณธาตุ คอมโบ เปิดช่อง และตั้งรับ ก่อนโล่/HP ไม่เพิ่มดาเมจพิษ/เผาไหม้
- สถานะเดินในเทิร์นเจ้าของรวมตัวสำรอง ตัวตายไม่ถูกใส่สถานะใหม่ สถานะเดิมรีเฟรช ไม่ซ้อนชั้น

ตัวอย่าง: บับเบิลบันโจมตีให้เปียก → อีกฝ่ายเล่น → สลับเห็ดจิ๋ว → อีกฝ่ายเล่น → โจมตีลมต่อคอมโบ ก่อนเปียกหมด หรือมอสซี่โจมตีสร้างราก → สลับฟ็อกซ์ฟู → โจมตีพื้นฐานต่อคอมโบอย่างรวดเร็ว การชาร์จเพิ่มเติมอาจทำให้รากหมดก่อนปล่อย ต้องเลือกจังหวะเอง

### เอฟเฟกต์สลับโดยสมัครใจ

| ตัวละคร | เอฟเฟกต์เข้าสนาม |
|---|---|
| ฟ็อกซ์ฟู | ATK +20% จนจบเทิร์นถัดไป |
| บับเบิลบัน | ล้างเผาไหม้/พิษตัวเอง และทำศัตรูเปียก 3 เทิร์น |
| มอสซี่ | ฟื้น HP ตัวเอง 15% และใส่รากยึดศัตรู 3 เทิร์น |
| ปุ๊กปิ๊ก | โล่ 35 หน่วย นาน 2 เทิร์น |
| เห็ดจิ๋ว | ใส่พิษศัตรู 3 เทิร์น |
| ปิ๊งปิ๊ง | พลังงาน +1 แต่รับดาเมจโจมตี +25% จนจบเทิร์นถัดไป |
| มิสตี้ | ลด ATK ศัตรู 25% เป็นเวลา 2 เทิร์นของศัตรู |
| โมจิมูน | ฟื้น HP ให้เพื่อนทุกตัวที่ยังมีชีวิต 8% |

ยังสลับได้ 3 ครั้ง ใช้หนึ่งเทิร์น ตัวเริ่มต้นและการเปลี่ยนฟรีเมื่อหมดสภาพไม่เปิดเอฟเฟกต์ เพื่อไม่ให้ได้ประโยชน์จากการเปลี่ยนฟรีซ้ำ โล่ใหม่แทนโล่เดิม ไม่เพิ่มสะสม ฮีลไม่นับส่วนเกินและไม่ชุบชีวิต สรุปการแข่งขันให้เครดิตฮีล/ดาเมจพิษจากเอฟเฟกต์แก่ตัวที่ลงสนาม

### ท่าพิเศษและตั้งรับ

- หางเพลิง: จ่ายพลังงาน 3 เพื่อชาร์จหนึ่งเทิร์น ไม่มีดาเมจในเทิร์นชาร์จ เทิร์นถัดไปกดท่าพิเศษอีกครั้งเพื่อปล่อยฟรี พลัง 240% พร้อมเผาไหม้ คูลดาวน์สองเทิร์นหลังปล่อย
- ระหว่างชาร์จ เลือกโจมตีพื้นฐาน/ตั้งรับ/สลับได้ แต่จะยกเลิกการชาร์จและไม่คืนพลังงาน สตันขัดจังหวะทันที ตัวหมดสภาพก็ยกเลิก การยกเลิกยังรักษาคูลดาวน์ที่เริ่มเมื่อชาร์จ
- หัวใจลุกโชนของปิ๊งปิ๊งยังเพิ่ม ATK 20% แต่แลกกับรับดาเมจโจมตี +25% จนจบเทิร์นถัดไป (ไม่เพิ่ม DOT)
- ตั้งรับใช้พลังงาน 1 ลดดาเมจโจมตีถัดไป 50% เมื่อรับสำเร็จได้พลังงานคืน 1 สูงสุด 6 ไม่คืนจาก DOT และคืนได้ครั้งเดียวต่อการตั้งรับ
- โล่/บัฟที่ใส่ตัวเองนับเทิร์นที่ใช้ด้วย สถานะที่ใส่ศัตรูนับเมื่อศัตรูจบเทิร์น

ข้อมูลความสามารถอยู่ src/tactics.js กติกาอยู่ src/engine.js และข้อความช่วยเล่นอยู่ src/tactical-ui.js ทั้งบอตและเซิร์ฟเวอร์ออนไลน์ใช้กติกาเดียวกัน มีการตรวจ charge/stun/พลังงาน/คูลดาวน์/โควตาและคำสั่งซ้ำบนเซิร์ฟเวอร์

ทดสอบเพิ่ม: เอฟเฟกต์ทั้ง 8 ตัว การเปลี่ยนฟรี คอมโบ/ใช้สถานะหมด/อายุสำรอง ชาร์จ/ปล่อย/ยกเลิก/สตัน เครดิตสรุปผล ตั้งรับคืนพลังงาน อ่อนแรง/เปิดช่อง เจตนาบอตคงแผน และแมตช์บอตจนจบ รวม integration ผ่าน WebSocket สองฝั่งสำหรับชาร์จ → ขัดจังหวะ → สลับ → คอมโบ

หลังอัปเดตให้รีเฟรชหน้าและเริ่มแมตช์ใหม่ ถ้าเปิดผ่าน tunnel ไปพอร์ต 3001 ใช้ npm run build เพื่อส่งหน้าใหม่ (build ล่าสุดแล้ว) เซิร์ฟเวอร์ที่ใช้ npm run dev จะรีโหลดกติกาเมื่อไฟล์เปลี่ยน ห้องเก่าจะหาย หากใช้ npm start ต้องรีสตาร์ตเซิร์ฟเวอร์ก่อนใช้กติกาใหม่

## ไอคอนที่แสดงผลเหมือนกันทุกอุปกรณ์

ไอคอนในหน้าหลัก การ์ด ธาตุ สถานะ พลังงาน ปุ่มสกิล และผลการแข่งขันใช้ SVG ภายในโปรเจกต์จาก `src/icons.js` แทน emoji ของระบบปฏิบัติการ ปุ่มที่มีเฉพาะไอคอนมีชื่อสำหรับโปรแกรมอ่านหน้าจอ หากเพิ่มไอคอนใหม่ให้เพิ่ม path ในไฟล์นี้และเรียก `icon(name)` ไม่ใส่ emoji ลงในข้อความเกมหรือบันทึกการต่อสู้
